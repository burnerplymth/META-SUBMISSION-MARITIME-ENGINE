# SupermAP

SupermAP is a supply-chain disruption terminal: pick a place and a disruption, and see how the effects spread to other places over time.

## Highlights

- Interactive map of ports, canals and hubs
- Step-by-step causal chain for each disruption
- Replays of recorded real-world disruptions
- Scenario and impact views
- Exportable reports

## Quick start

Requires Python 3.10+ and Node 20+, or Docker.

```bash
./run.sh
```

Then open http://127.0.0.1:8143. No API key is needed — the default mode runs offline on recorded data.
